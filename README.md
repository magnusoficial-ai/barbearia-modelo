# barbearia-modelo

Landing page de demonstração de uma barbearia fictícia em Teresina-PI. Um arquivo HTML estático, sem build e sem dependências.

## Arquivos

- `index.html`: a página inteira (HTML, CSS e um pouco de JavaScript).
- `fontes/`: Geist e Geist Mono, servidas pelo próprio site (licença OFL em `fontes/OFL.txt`).
- `fotos/`: as fotos da barbearia. Veja `fotos/LEIA-ME.txt` para os nomes e tamanhos.

## Como adaptar para um cliente

Abra `index.html` e procure os comentários `TROQUE AQUI`. Eles indicam o número do WhatsApp, as fotos, o endereço, o mapa, os preços, os horários e o Instagram.

Os horários ficam em um lugar só: a lista da seção "Onde fica". O aviso "Aberto até as 19h" / "Fechado, abre amanhã às 9h" no topo é calculado a partir dela, no fuso de Teresina.

A página segue o tema do aparelho (claro ou escuro).

## Ver no computador

Abra `index.html` no navegador. Para publicar, envie `index.html`, `fontes/` e `fotos/` juntos.
